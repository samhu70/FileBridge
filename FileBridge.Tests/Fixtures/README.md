# Certificate compatibility fixtures

`legacy-fb3.pfx` contains a deliberately public test key generated by FileBridge 2.5.9.
Its certificate includes the original UUID-sized public-key-pinning OID. It verifies
that an existing saved identity can be read and reused on Windows without changing
its public key or requiring users to recreate their connection codes.

This key is for automated tests only. Never use it for actual transfers.
